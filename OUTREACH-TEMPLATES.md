## Personalization Checklist

For every email sent, complete before sending:

- [ ] Reference the specific funding amount and stage from their announcement
- [ ] Check if [Company] actually appears in ChatGPT for a relevant query (takes 30 seconds)
- [ ] Note one specific finding if possible (missing from ChatGPT, competitor mentioned instead, wrong founder credited, etc.)
- [ ] Use the founder's actual first name (not "Founder" or "CEO")
- [ ] Confirm the TechCrunch or Crunchbase article URL for credibility

## Sending Cadence

- Send 5-10 emails per day (not batch — spread across mornings, Tue-Thu)
- Track open rates, reply rates, and audit purchases per template
- A/B test Template 1 vs Template 2 after 20 sends each
- Kill the underperformer, scale the winner
